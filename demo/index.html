Plantasia Sound Engine

What it is

An instrument that plays itself and answers you. Plantasia Sound Engine is a library for the browser: load a species and it composes on its own; touch a key, a slider or a wheel and it responds. This page is its control surface, a test bench that exposes everything the engine can do. Instrument apps built on the engine own their own screens.

What it does

Four botanical species, Seed, Flowers, Mold and Bacteria, each with its own synthesis graph and generator. Five ecological controls shared by all of them: growth, bloom, roots, mold, bacteria. Notes from a keyboard or MIDI, a mod wheel routed anywhere through modulation, and snapshots that save and recall the whole state as one JSON object with a timed morph between two. Every musical moment comes back as an event stamped with the audio clock, with per frame audio analysis, so visuals can follow the sound.

What it is for

Plantasonic instruments: apps where sound behaves like a living thing rather than a preset. The engine owns the sound once, so each app does not re-implement how sound grows, ages and answers a player. Hosts import one function and get thirty four methods on one documentation page; seven of them are the whole playing surface.

How it is made

TypeScript on Web Audio through Tone.js, with Web MIDI for input, built with Vite. Species are plugins registered in a registry; a lifecycle state machine, an event bus, a master bus with analysis, a scheduler and transport, a modulation engine and a snapshot layer sit under one facade. Nineteen validation gates run on every build. A Playwright harness plays the built engine in Chromium and WebKit, locally and in CI, and measures what a player feels: about 12 ms from a key to sound, zero dropouts through a minute of playback and a five second morph, six lines from an empty file to the first note. Designed and built by Nate Johnson, 2026.
