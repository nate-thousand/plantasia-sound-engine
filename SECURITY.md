# Security Policy

## Supported versions

Only the latest version on the `main` branch is actively maintained.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting from this repository's **Security** tab when that option is available. If private reporting is unavailable, open an issue requesting a private contact channel, but do not include vulnerability details.

Never place API keys, credentials, personal data, or exploit details in a public issue.

A report should include the affected area, reproduction steps, expected impact, and any suggested mitigation.
